# Racing Line

An overhead Formula-style racing game in a single HTML page: 8 circuits, 5 teams, AI opponents, DRS, slipstream, track limits, tyre wear, weather and more.

Play it: open `index.html` in a browser, or visit the GitHub Pages site for this repository.

Online multiplayer only works in the claude.ai version (it uses claude.ai's room service); everything else works here.
